# Deteccion-de-neumonia-aplicando-Deep-Learning

```
    Prueba nuestro detector: https://detector-de-neumonia.streamlit.app/
```

Este trabajo aborda la detección de neumonía aplicando Deep Learning. Este trabajo abarca:
- Un notebook donde se entrenan 3 modelos (ResNet-18, EfficientNet-B0 y DenseNet-121) con 4 resoluciones de radiografía (28, 64, 128 y 224 px)
- Una aplicación web cuyo desarrollo está en [(https://detector-de-neumonia.streamlit.app/)](https://github.com/Chavaper/detector-de-neumonia)
- La referencia principal de este trabajo es el paper [**MedMNIST v2 - A large-scale lightweight benchmark for 2D and 3D biomedical image classification**](https://pmc.ncbi.nlm.nih.gov/articles/PMC9852451/)
