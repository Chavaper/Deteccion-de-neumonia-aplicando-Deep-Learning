# Deteccion-de-neumonia-aplicando-Deep-Learning

Este trabajo aborda la detección de neumonía aplicando Deep Learning. Para ello, se tiene:
- Un notebook donde se entrena tres modelos con resoluciones de imágenes diferentes. 
- Una aplicación web que prueba nuestro modelo de DL escogido para detectar neumonía (https://detector-de-neumonia.streamlit.app/)
- Más info sobre la app web: https://github.com/Chavaper/detector-de-neumonia
