# Deteccion-de-neumonia-aplicando-Deep-Learning

Este trabajo aborda la detección de neumonía aplicando Deep Learning. Para ello, se tiene:
- Un notebook donde se entrena 3 modelos con 4 resoluciones de imágenes diferentes.
    - Los modelos son: ResNet-18, EfficientNet-B0 y DenseNet-121
    - Las resoluciones son: 28, 64, 128 y 224 px
- Una aplicación web que prueba nuestro modelo de DL escogido para detectar neumonía (https://detector-de-neumonia.streamlit.app/)
- Más info sobre la app web: https://github.com/Chavaper/detector-de-neumonia

<br>

La referencia principal de este trabajo es el paper [**MedMNIST v2 - A large-scale lightweight benchmark for 2D and 3D biomedical image classification**](https://pmc.ncbi.nlm.nih.gov/articles/PMC9852451/)
